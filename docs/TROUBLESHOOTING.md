# Troubleshooting — если что-то не работает

Для безопасной проверки установки запустите обычный doctor:

```bash
# macOS / Linux
node ~/.telegram-mcp/server/doctor.mjs ~/.telegram-mcp/run.sh
```

```powershell
# Windows
node "$env:USERPROFILE\.telegram-mcp\server\doctor.mjs" cmd /c "$env:USERPROFILE\.telegram-mcp\run.cmd"
```

Обычный doctor работает без авторизованной сессии. Его вывод всё равно просмотрите перед передачей: не публикуйте вместе с ним личные данные или пути. Для проверки аккаунта используйте `doctor.mjs --status` (он вызывает только `telegram-status`).

## Установка

### «node: command not found» / «не является командой»

Node.js не установлен или терминал открыт до установки. Установите LTS с [nodejs.org](https://nodejs.org) и **закройте-откройте терминал заново**. Проверка: `node -v`.

### Node.js установлен, но версия ниже 22

Скачайте свежий LTS с [nodejs.org](https://nodejs.org) — он поставится поверх. Если пользуетесь nvm: `nvm install --lts && nvm alias default lts/*`.

### Windows: «выполнение сценариев отключено в этой системе»

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

Ответьте `Y`, затем запустите установщик снова. Это разовая настройка, влияет только на вашего пользователя.

### npm install падает с ошибкой сети / EACCES

- Проверьте интернет; если корпоративная сеть — попробуйте с домашней или с телефона (раздача).
- EACCES по правам: не запускайте установщик через `sudo` — он ставит всё в вашу домашнюю папку, root не нужен.
- Если используете VPN и registry.npmjs.org недоступен — отключите/включите VPN.

## Вход (QR-код)

### QR-код не сканируется / «поплыл» в терминале

- Разверните окно терминала на весь экран, при необходимости уменьшите шрифт (Cmd/Ctrl + минус) — код перерисуется.
- Экран грязный/тёмный — поднимите яркость, телефон ближе.
- Альтернатива: если сервер уже подключён к Claude Desktop, войти можно прямо из чата — напишите Claude «Выполни telegram-login». В этом случае QR дополнительно сохраняется картинкой `~/.telegram-mcp/qr-login.png` (Windows: `C:\Users\<вы>\.telegram-mcp\qr-login.png`) — откройте файл и сканируйте с него.

### Где в Telegram сканер QR?

Телефон → Telegram → **Настройки → Устройства → Подключить устройство**. (На iPhone «Настройки» — правый нижний угол.)

### Ошибка «2FA is enabled… Set TELEGRAM_2FA_PASSWORD»

У вас включён **облачный пароль (2FA)**, а при входе он не был передан. Установщик спрашивает про 2FA **до** показа QR-кода — запустите установщик заново и на вопрос «Включён ли у вас облачный пароль (2FA)?» ответьте `y`, затем введите пароль (он используется только в момент входа и нигде не сохраняется).

Вход вручную, без установщика:

```bash
# macOS / Linux (пробел перед командой не случаен — так она не попадёт в историю shell)
 TELEGRAM_2FA_PASSWORD='ваш_облачный_пароль' ~/.telegram-mcp/run.sh login
```

```powershell
# Windows
$env:TELEGRAM_2FA_PASSWORD = Read-Host "Облачный пароль" -AsSecureString | ForEach-Object { [Runtime.InteropServices.Marshal]::PtrToStringAuto([Runtime.InteropServices.Marshal]::SecureStringToBSTR($_)) }
& "$env:USERPROFILE\.telegram-mcp\run.cmd" login
Remove-Item Env:TELEGRAM_2FA_PASSWORD
```

Если пароль забыли — восстановите его в приложении Telegram (Настройки → Конфиденциальность → Облачный пароль), затем повторите вход.

### QR отсканировался, но вход не завершился / ошибка таймаута

Запустите вход заново:

```bash
# macOS / Linux
~/.telegram-mcp/run.sh login
```

```powershell
# Windows
& "$env:USERPROFILE\.telegram-mcp\run.cmd" login
```

(Если включён 2FA — сначала задайте `TELEGRAM_2FA_PASSWORD`, см. раздел выше.)

## Claude не видит сервер

### В Claude Desktop нет инструментов telegram

1. Перезапустили ли вы Claude Desktop **полностью**? macOS: Cmd+Q. Windows: правой кнопкой по значку в трее → выход. Просто закрыть окно недостаточно.
2. Проверьте конфиг (пути в [05-claude-desktop.md](05-claude-desktop.md)): JSON валиден? Блок `telegram` внутри `mcpServers`?
3. Claude Desktop → Settings → Developer — сервер `telegram` должен быть в списке. Если у него статус failed — нажмите Open Logs и посмотрите последние строки.
4. Прогоните доктора (команда в начале страницы): если доктор работает, а Desktop нет — проблема в конфиге Desktop, а не в сервере.

### В Claude Code `/mcp` не показывает telegram

```bash
claude mcp list
```

Если сервера нет — подключите заново: [06-claude-code.md](06-claude-code.md). Если есть, но failed — запустите доктора.

### Сервер был, работал, а после обновления Node.js сломался

Обёртка запоминает путь к node на момент установки. Если вы переустановили/обновили Node.js и путь изменился — просто запустите установщик ещё раз (ключи и сессию он предложит оставить).

## Ошибки Telegram

### AUTH_KEY_DUPLICATED

Один session-файл могут использовать **не более одного процесса одновременно**. Ошибка значит, что два процесса столкнулись, и Telegram аннулировал сессию.

В нашей установке такое почти невозможно: сервер сам работает по схеме «один владелец — остальные клиенты» ([подробно](08-multi-agent.md)). Если ошибка всё же появилась — обычно это две РАЗНЫЕ папки сессии на один аккаунт (например, вручную скопировали `~/.telegram-mcp` или настроили второй конфиг со своим `TELEGRAM_SESSION_PATH`).

Лечение:
1. Закройте все AI-агенты (и остановите фоновый сервис, если есть: `~/.telegram-mcp/daemon-setup.sh remove`).
2. Убедитесь, что на аккаунт осталась одна папка сессии — `~/.telegram-mcp`.
3. Войдите заново: `~/.telegram-mcp/run.sh login` (Windows: `& "$env:USERPROFILE\.telegram-mcp\run.cmd" login`; при 2FA см. раздел выше).
4. Верните фоновый сервис: `~/.telegram-mcp/daemon-setup.sh install`.

### Работаю с несколькими агентами — у одних Telegram есть, у других отвалился

Владельцем соединения стал один из агентов, и вы его закрыли. Настройте фоновый сервис — он всегда владеет соединением, и закрытие агентов ни на что не влияет: [08-multi-agent.md](08-multi-agent.md).

### Windows: в логах «listen EACCES … daemon.sock»

Запустите поддерживаемый `install.ps1` ещё раз, чтобы обновить закреплённый runtime и повторить проверку. При запросе оставьте текущие ключи и выберите не входить заново, если сессия сохранна.

### FLOOD_WAIT_X

Telegram просит подождать X секунд — вы (или Claude) сделали слишком много запросов подряд. Просто подождите указанное время. Если Claude часто в это упирается — просите его делать меньше действий за раз.

### «Connecting to … 80/TCPFull» висит вечно (VPS/хостинг)

Провайдер режет порт 80 к серверам Telegram. Добавьте в `~/.telegram-mcp/telegram.env` строку:

```
TELEGRAM_USE_WSS=true
```

### Telegram заблокирован в вашей сети

Настройте SOCKS5-прокси или MTProxy: [ADVANCED.md](ADVANCED.md#прокси-socks5--mtproxy).

### Аккаунт разлогинился сам

Telegram мог завершить сессию (например, вы нажали «Завершить все сеансы» на телефоне, либо долго не пользовались). Войдите заново через `login` — см. выше.

## Прочее

### Хочу перенести на другой компьютер

Не копируйте файлы! На новом компьютере запустите установщик и войдите по QR заново — это создаст **отдельную** сессию, обе будут работать независимо.

### Как посмотреть версию сервера

```bash
cat ~/.telegram-mcp/server/node_modules/@overpod/mcp-telegram/package.json | grep '"version"'
```

### Ничего не помогло

Соберите и приложите к вопросу (Issue в репозитории или чат поддержки):
1. Вашу ОС и версию (`macOS 14 / Windows 11 / Ubuntu 24.04`).
2. `node -v`
3. Полный вывод доктора.
4. Что именно делали и что увидели (скриншот терминала, БЕЗ содержимого telegram.env!).
