# Установка на Windows — пошагово

Подходит для Windows 10 и Windows 11.

## Шаг 1. Установите Node.js (если ещё нет)

Откройте **PowerShell**: нажмите Пуск, введите `PowerShell`, нажмите Enter. Проверьте:

```powershell
node -v
```

- Если видите версию `v18.x` или новее (например `v22.17.0`) — переходите к шагу 2.
- Если видите ошибку «не является… командой» — установите Node.js:

**Вариант А (самый простой):** зайдите на [nodejs.org](https://nodejs.org), нажмите зелёную кнопку **LTS**, запустите скачанный `.msi` и прощёлкайте установщик (все галочки по умолчанию). После установки **закройте и заново откройте PowerShell**.

**Вариант Б (через winget):**

```powershell
winget install OpenJS.NodeJS.LTS
```

После установки тоже перезапустите PowerShell.

## Шаг 2. Получите api_id и api_hash

Если ещё не получили — [инструкция на 5 минут](01-api-keys.md).

## Шаг 3. Запустите установщик

Вставьте в PowerShell одну команду:

```powershell
irm https://raw.githubusercontent.com/alexfisenkov/telegram-mcp-starter/main/install.ps1 | iex
```

> **Ошибка «выполнение сценариев отключено»?** Выполните сначала:
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
> ```
> Ответьте `Y` и запустите установщик снова. Это разовая настройка.

Установщик проведёт вас по шести шагам. Что он будет спрашивать:

1. **Ничего** — проверит Node.js сам.
2. **Ничего** — установит сервер в `C:\Users\<вы>\.telegram-mcp\server` (закреплённая версия, у всех одинаковая).
3. **TELEGRAM_API_ID** и **TELEGRAM_API_HASH** — вставьте значения из шага 2 (правая кнопка мыши = вставить в PowerShell). Ввод api_hash скрыт — звёздочки не показываются, это нормально. Ключи сохранятся в `telegram.env`, доступ к файлу будет только у вашего пользователя Windows.
4. **QR-код** — сначала установщик спросит, включён ли у вас облачный пароль (2FA), и если да — попросит ввести его **до** показа QR-кода (пароль нигде не сохраняется). Затем в окне появится QR-код. Возьмите телефон: **Telegram → Настройки → Устройства → Подключить устройство** и отсканируйте.
   > QR-код выглядит «поехавшим»? Разверните окно PowerShell на весь экран или уменьшите шрифт (Ctrl + колесо мыши) и подождите — код перерисуется.
5. **Подключение к Claude** — на вопросы про Claude Code и Claude Desktop отвечайте `y`, если пользуетесь ими. Перед изменением конфига Claude Desktop создаётся резервная копия.
6. **Проверка** — «доктор» сам подключится к серверу и покажет имя вашего аккаунта.

## Шаг 4. Перезапустите Claude

- **Claude Desktop:** закройте полностью — правой кнопкой по значку Claude в трее (возле часов) → выход, затем откройте заново.
- **Claude Code:** откройте новую сессию, наберите `/mcp` — в списке должен быть `telegram`.

## Шаг 5. Проверьте

Напишите Claude: **«Выполни telegram-status»**. В ответ придёт имя вашего аккаунта.

Дальше: [что попросить у Claude в первую очередь](07-verify.md) · [правила безопасности](SECURITY.md)

## Если что-то пошло не так

[TROUBLESHOOTING.md](TROUBLESHOOTING.md) — там разобраны все типовые ошибки. Быстрая самодиагностика:

```powershell
node "$env:USERPROFILE\.telegram-mcp\server\doctor.mjs" cmd /c "$env:USERPROFILE\.telegram-mcp\run.cmd"
```
