# FAQ — частые вопросы

## Про безопасность и приватность

**Меня забанят в Telegram?**
За само подключение — нет. MTProto-подключение выглядит для Telegram как ещё одно десктопное приложение (вы увидите его в «Устройствах»). Банят за поведение: спам незнакомым людям, массовые рассылки, автодобавления в группы. Пользуйтесь как обычный человек, просто руками Claude — и всё будет хорошо. Подробнее: [SECURITY.md](SECURITY.md).

**Claude читает все мои переписки?**
Нет. Claude видит только то, что вы попросили прочитать в конкретном запросе. Он не «сидит» в аккаунте постоянно — каждый инструмент вызывается по вашей команде в чате.

**Куда уходят мои данные?**
Сервер работает на вашем компьютере и общается только с серверами Telegram. Тексты, которые вы попросили прочитать, попадают в ваш разговор с Claude (то есть обрабатываются Anthropic, как любой ваш чат с Claude). Никаких третьих сервисов нет.

**Что за файлы telegram.env и session? Можно их куда-то скопировать?**
Это ключи от аккаунта. Никуда не копируйте и никому не отправляйте. Подробно: [SECURITY.md](SECURITY.md).

**Как экстренно всё отключить?**
Телефон → Telegram → Настройки → Устройства → завершите сессию. Доступ отзывается мгновенно.

**Нужен ли Telegram Premium?**
Нет. Premium нужен только для отдельных инструментов (например, транскрибация голосовых силами Telegram или эмодзи-статусы).

## Про установку

**Я совсем не программист. Справлюсь?**
Да. Вся установка — это: скачать Node.js с официального сайта → получить два ключа на my.telegram.org → вставить одну команду в терминал и отвечать y/n. Инструкции написаны именно для вас: [macOS](02-macos.md) · [Windows](03-windows.md).

**Почему нужен какой-то api_id? У других MCP такого нет.**
Мы подключаемся к Telegram напрямую по протоколу MTProto — как настоящее приложение. Telegram требует, чтобы у каждого такого приложения были свои ключи разработчика. Это бесплатно и занимает 5 минут: [01-api-keys.md](01-api-keys.md).

**Можно без Node.js?**
Да, у исходного проекта есть готовые бинарники под все ОС: [ADVANCED.md](ADVANCED.md#запуск-без-nodejs-готовые-бинарники). Но путь с Node.js проще поддерживать, рекомендуем его.

**У меня два аккаунта Telegram. Можно оба?**
Можно: [ADVANCED.md](ADVANCED.md#несколько-аккаунтов).

**Работает в Cursor / VS Code / других клиентах?**
Да, в любом MCP-клиенте: [ADVANCED.md](ADVANCED.md#другие-mcp-клиенты) и готовые примеры в [configs/](../configs/).

**Как обновить сервер?**
Запустите установщик ещё раз — он поставит закреплённую в нём версию. Ключи и вход сохранятся.

**Телефон нужен каждый раз?**
Нет, только один раз при входе (сканировать QR). Дальше сессия живёт на компьютере.

## Про использование

**С чего начать?**
[07-verify.md](07-verify.md) — готовые первые промпты.

**Claude может отправить что-то без моего ведома?**
Claude вызывает инструменты в рамках вашего запроса и показывает, что делает. Хорошая практика для важных чатов — попросить: «сначала покажи текст, отправляй только после моего подтверждения». В Claude Code вызовы инструментов дополнительно проходят через систему разрешений.

**Какие самые полезные сценарии?**
- Утренняя сводка: «что мне написали за ночь, по важности»
- Поиск: «найди, где мы договаривались о цене с подрядчиком»
- Секретарь: «вежливо ответь всем, кому я не ответил за 3 дня, что я на связи завтра»
- Каналы: «сводка постов канала X за неделю, главные мысли»
- Файлы: «вытащи все PDF из чата Бухгалтерия за март в папку на рабочем столе»

**Почему Claude иногда говорит «подожду N секунд»?**
Это лимиты Telegram (FLOOD_WAIT) — защита от слишком частых запросов. Норма, просто подождите.

**Инструментов ~170 — Claude не запутается?**
Нет, Claude сам выбирает нужный инструмент по вашей просьбе на обычном языке. Список для любопытных: [TOOLS.md](TOOLS.md).
