# Шаг 0. Получаем api_id и api_hash (5 минут)

`api_id` и `api_hash` — это ваши **личные ключи разработчика Telegram**. Они бесплатные, выдаются самим Telegram на странице [my.telegram.org](https://my.telegram.org) и нужны любому приложению, которое работает с Telegram напрямую (по протоколу MTProto). Без них подключение невозможно.

> **Важно:** ключи привязаны к вашему аккаунту. Это НЕ пароль от аккаунта, но вместе с файлом сессии они дают полный доступ. Никому их не передавайте и не публикуйте.

## Пошагово

1. Откройте в браузере **https://my.telegram.org**

2. Введите свой номер телефона **в международном формате** (например, `+79991234567`) и нажмите **Next**.

3. Telegram пришлёт **код подтверждения в приложение Telegram** (НЕ по SMS!). Откройте Telegram на телефоне — код будет в чате «Telegram». Введите его на сайте.

   > Если кода нет — проверьте чат с названием «Telegram» (синий значок с галочкой) и папку «Архив».

4. После входа нажмите **API development tools**.

5. Если приложение ещё не создано, заполните форму (данные ни на что не влияют, можно писать что угодно осмысленное):
   - **App title:** например `My Claude MCP`
   - **Short name:** например `claudemcp` (5–32 латинских символа)
   - **Platform:** `Desktop`
   - **Description:** можно оставить пустым
   
   Нажмите **Create application**.

6. На открывшейся странице вы увидите:
   - **App api_id** — число, например `1234567`
   - **App api_hash** — строка из 32 символов, например `0123456789abcdef0123456789abcdef`

7. **Скопируйте оба значения** в надёжное место (менеджер паролей — идеально). Они понадобятся установщику на шаге 3.

## Частые проблемы

| Проблема | Решение |
|----------|---------|
| «ERROR» без объяснений при входе на сайт | Telegram иногда блокирует вход с VPN/прокси. Отключите VPN и попробуйте снова. Иногда помогает другой браузер или подождать пару часов. |
| Код подтверждения не приходит | Код приходит **в приложение Telegram** (чат «Telegram»), не по SMS. |
| Забыл, где взять ключи повторно | Снова зайдите на my.telegram.org → API development tools — там те же значения. Ключи выдаются один раз и не меняются. |
| Сайт просит «Delete app»? | Ничего не удаляйте — просто скопируйте api_id и api_hash с текущей страницы. |
