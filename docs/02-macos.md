# Установка на macOS — пошагово

Подходит для любых Mac (Intel и Apple Silicon), macOS 12 и новее.

## Шаг 1. Установите Node.js (если ещё нет)

Проверьте, есть ли Node.js. Откройте **Терминал** (Cmd+Пробел → «Терминал») и выполните:

```bash
node -v
```

- Если видите версию `v18.x` или новее (например `v22.17.0`) — всё готово, переходите к шагу 2.
- Если видите `command not found` или версию ниже 18 — установите Node.js:

**Вариант А (самый простой):** зайдите на [nodejs.org](https://nodejs.org), нажмите зелёную кнопку **LTS**, откройте скачанный `.pkg` и прощёлкайте установщик. После установки **закройте и заново откройте Терминал**.

**Вариант Б (если пользуетесь Homebrew):**

```bash
brew install node
```

## Шаг 2. Получите api_id и api_hash

Если ещё не получили — [инструкция на 5 минут](01-api-keys.md).

## Шаг 3. Запустите установщик

Вставьте в Терминал одну команду:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/alexfisenkov/telegram-mcp-starter/main/install.sh)
```

Установщик проведёт вас по шести шагам. Что он будет спрашивать:

1. **Ничего** — проверит Node.js сам.
2. **Ничего** — установит сервер в `~/.telegram-mcp/server` (закреплённая версия, у всех одинаковая).
3. **TELEGRAM_API_ID** и **TELEGRAM_API_HASH** — вставьте значения из шага 2. Ввод api_hash скрыт (звёздочки не показываются — это нормально, просто вставьте и нажмите Enter). Ключи сохранятся в `~/.telegram-mcp/telegram.env` с правами «только ваш пользователь».
4. **QR-код** — сначала установщик спросит, включён ли у вас облачный пароль (2FA), и если да — попросит ввести его **до** показа QR-кода (пароль нигде не сохраняется). Затем в Терминале появится QR-код. Возьмите телефон: **Telegram → Настройки → Устройства → Подключить устройство** и отсканируйте.
5. **Подключение к Claude** — на вопросы про Claude Code и Claude Desktop отвечайте `y`, если пользуетесь ими. Перед изменением конфига Claude Desktop создаётся резервная копия.
6. **Проверка** — «доктор» сам подключится к серверу и покажет имя вашего аккаунта.

## Шаг 4. Перезапустите Claude

- **Claude Desktop:** полностью закройте (Cmd+Q, не просто окно) и откройте заново.
- **Claude Code:** откройте новую сессию, наберите `/mcp` — в списке должен быть `telegram`.

## Шаг 5. Проверьте

Напишите Claude: **«Выполни telegram-status»**. В ответ придёт имя вашего аккаунта.

Дальше: [что попросить у Claude в первую очередь](07-verify.md) · [правила безопасности](SECURITY.md)

## Если что-то пошло не так

[TROUBLESHOOTING.md](TROUBLESHOOTING.md) — там разобраны все типовые ошибки. Быстрая самодиагностика:

```bash
node ~/.telegram-mcp/server/doctor.mjs ~/.telegram-mcp/run.sh
```
