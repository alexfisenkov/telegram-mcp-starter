# Инструкция AI-агенту: локально подключить Telegram MCP

Этот плейбук предназначен для пользователя, который попросил установить Telegram MCP в его локальный клиент. Следуй действующему установщику проекта; не собирай runtime вручную и не заменяй его прямой установкой npm-пакета.

## Границы

Telegram MCP использует MTProto и авторизованную сессию пользовательского аккаунта. После подключения инструменты могут читать данные аккаунта и выполнять действия от его имени. Работай только в пределах прямого поручения владельца, соблюдай [правила безопасного использования](docs/SECURITY.md), а перед важной отправкой показывай пользователю точный текст и адресата.

Не проси присылать в чат с AI `api_hash`, пароль 2FA, QR-код, файл `telegram.env` или файл сессии. Установщик запрашивает ключи и пароль непосредственно в локальном терминале; пользователь сам сканирует QR телефоном. Если интерфейс установщика не позволяет безопасно передать данные, остановись и попроси пользователя продолжить локально. Не имитируй вход, не используй реальные аккаунты в тестах.

## Установка

1. Проверь Node.js 22 или новее. Если его нет, объясни, что требуется локальная установка Node.js LTS; не устанавливай системные компоненты без прямого согласия пользователя.
2. Предложи пользователю запустить официальный установщик из репозитория:

   **macOS / Linux:**
   ```bash
   bash <(curl -fsSL https://raw.githubusercontent.com/alexfisenkov/telegram-mcp-starter/main/install.sh)
   ```

   **Windows PowerShell:**
   ```powershell
   irm https://raw.githubusercontent.com/alexfisenkov/telegram-mcp-starter/main/install.ps1 | iex
   ```

   Запуск интерактивный: пользователь вводит ключи и пароль 2FA в локальном prompt установщика и сканирует QR телефоном. Не проси копировать секреты сюда. Установщик устанавливает закреплённый дистрибутив, подключает обнаруженные поддерживаемые клиенты и в конце выполняет авторизованную readiness-проверку.
3. При повторной установке установщик спрашивает, сохранить ли существующие ключи и входить ли заново. Для обычного обновления сохраняют ключи и выбирают без повторного входа. Установщик создаёт резервную копию предыдущего каталога runtime и сохраняет клиентские настройки при их обновлении.
4. Объясни пользователю, как перезапустить подключённый клиент. Успешное завершение установщика подтверждает локальную проверку `telegram-status`; оно не проверяет все операции аккаунта.

Не скачивай ветку `main` вручную и не копируй отдельные файлы в установленный сервер. Установщик разрешает release tag `v2.0.0` в один полный commit SHA, получает архив этого коммита и применяет hash-bound runtime postimages. Обычные upstream npm/npx-пакеты и бинарники сами по себе не содержат эти расширения.

## Проверка и диагностика

У установленного доктора без флага `--status` безопасный режим: MCP initialize + tools/list запускаются с тестовыми параметрами, отсутствующей сессией во временном пути и нерабочим локальным proxy. Он проверяет каталог инструментов, не авторизуется в Telegram и не вызывает инструменты аккаунта.

`doctor.mjs --status` — отдельная авторизованная read-only проверка: она использует обычную обёртку пользователя, запрашивает каталог инструментов и вызывает только `telegram-status`. Установщик запускает именно этот вариант и требует подтверждения подключённого owner. Не запускай status mode как синтетический тест и не подменяй его утверждением, что пользовательский аккаунт проверен.

Инструкции: [проверка](docs/07-verify.md), [неполадки](docs/TROUBLESHOOTING.md), [безопасность](docs/SECURITY.md), [инструменты](docs/TOOLS.md), [архитектура и выпуск](docs/ARCHITECTURE.md).

## Что не делать

- Не устанавливай upstream напрямую через `npm install`, `npx` или скачанный upstream binary: это обходит закреплённый lockfile и проектные расширения.
- Не публикуй и не пересылай ключи, сессию, приватные чаты или данные аккаунта.
- Не отправляй сообщения, не подписывайся на каналы и не меняй настройки без конкретного поручения пользователя.
- Не утверждай, что Windows service, browser automation или конкретная операция Telegram проверена в production без отдельного фактического подтверждения.
